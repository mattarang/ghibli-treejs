# B (second set)

**Premise.** Toon shading: light falls in three hard steps, never a ramp. So three weights, three sizes, three inks and three spacings, with nothing in between.

**Fonts and licence.** Ronzino (Collletttivo, Italy), Regular/Medium/Bold, SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #2a2233; lit #f3d9a4 (11.1:1, values and name, bold); mid #c98f6b (5.5:1, section names, medium); shade #a58aa8 (4.9:1, labels, regular).

**Rules.** Sizes only 16 / 26 / 64 px; spacing only 8 / 16 / 48 px; one 760 px column; label left, value right.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
