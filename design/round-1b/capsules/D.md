# D (second set)

**Premise.** The season wheel: four quarters, the year turning clockwise. The panel's parts sit in the four quarters of the page, each in its season's ink.

**Fonts and licence.** Messapia (Collletttivo, Italy), Regular/Bold, SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #e8edf2; spring #a3365e (5.5:1, name, time, actions); summer #2d6638 (5.8:1, Crown); autumn #9a4a12 (5.3:1, Branches); winter #34507a (6.9:1, Trunk).

**Rules.** Page split 2x2; each quarter aligned to its outer corner; section names 4.2vw bold; rows 16px. Phones stack the quarters.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
