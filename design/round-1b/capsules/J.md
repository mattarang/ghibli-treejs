# J (second set)

**Premise.** The herbarium sheet: the tree is the specimen and the sheet is left to it; everything written about it is one small label in the corner, one weight, as a botanist's label is, the measured values in the hand's ink.

**Fonts and licence.** Absans (Collletttivo, Italy), Regular, SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #e6e9e1; primary #2b2b28 (11.6:1); values and season #7d2f2f (7.4:1).

**Rules.** One 290px label at the bottom right; 13px throughout, name 20px; a label table with values right-aligned; the rest of the page empty.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
