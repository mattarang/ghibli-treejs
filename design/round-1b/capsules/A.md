# A (second set)

**Premise.** The crown is made of lobes, clumps of leaves with air between them: each section of the panel is one clump, tight inside, with wide gaps between, set at different places like a crown's masses.

**Fonts and licence.** Apfel Grotezk (Collletttivo, Italy), Regular/Fett/Satt, SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #e4ebe6; primary #1d2b24 (12.2:1); secondary #4f6a5b (4.9:1, labels and month).

**Rules.** 12-column grid; lobes on columns 2-6, 7-11, 4-8; leading 1.15 inside a lobe, 7vh between; name 6.4vw Satt; values bold tabular figures.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
