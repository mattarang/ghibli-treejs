# F (second set)

**Premise.** Growth order: trunk first, then limbs, then crown. Read from the foot up, each stage is set in a wider cut of one family: condensed trunk, regular branches, expanded crown.

**Fonts and licence.** Halibut (Collletttivo, Italy), Condensed/Regular/Expanded in Thin and Regular, SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #d5e2ee; one ink #17324d (10.0:1).

**Rules.** Bottom-anchored; Crown at top in Expanded, Branches in Regular, Trunk in Condensed, the name at the foot 10vw Condensed; labels Thin, values Regular; pairs run inline.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
