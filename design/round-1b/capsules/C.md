# C (second set)

**Premise.** The crown's shadow lies on the grass down and to the right of it: every value and the name carry a pale shadow copy just behind them.

**Fonts and licence.** Ortica Linear Light/Regular and Ortica Angular Bold (Collletttivo, Italy), SIL OFL 1.1, via jsDelivr.

**Colour.** Canvas #d6e6a8 (sunlit grass); primary #22331a (10.1:1); shadow #9fbb6c (1.6:1: a decorative, screen-reader-hidden repeat behind the readable text, never read on its own).

**Rules.** Values 30px Angular Bold with shadow offset .06em/.07em; labels 14px Light above; three columns; name 9vw.

**Assumptions and risks.** Working copy is the Shape panel's real labels and default values for the camphor tree, plus the season, time, actions and loading step. Fonts load from GitHub branches through jsDelivr (not pinned to a release).

**Into Round 2.** Carry the premise into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
