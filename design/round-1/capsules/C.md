# C

**Premise.** The crown is painted stroke by stroke in four tone bands (shade, middle, light, rim); dabs overlap. The four tones become four text roles in one dense mass.

**Fonts and licence.** Overused Grotesk VF (RandomMaerks, France), wght 300-900, SIL OFL 1.1, via jsDelivr; fallback sans-serif.

**Colour.** Canvas #0e2f3a; accent rim #ece6a4 (11.0:1, the name); primary light #9cc95e (7.4:1, values and season); secondary middle #4f8f4f (3.6:1, large labels only); tertiary shade #729c8f (4.6:1, actions).

**Rules.** Line-height .78-.84 so lines nearly touch; 13.5vw name, 7.4vw rows; weight 850 values against weight 300 labels in the same line; rows alternate left and right.

**Signature relationship.** Four tones doing four jobs inside one packed mass.

**Must stay if it continues.** Density; the four-tone role order; heavy/light pairing within a line.

**Assumptions and risks.** Working copy is the demo's own UI words. Fonts load from GitHub branches through jsDelivr (not pinned to a release). The shade tone had to be lifted for contrast, so it is now lighter than the middle tone: the tone order is broken there.

**Into Round 2.** Carry the signature relationship into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
