# I

**Premise.** The wind has blown from the left all season: everything has gathered against the downwind edge, leaning the way it blows; only the tree's own name stands upright and rooted.

**Fonts and licence.** Monaspace Radon VF (GitHub Next, US), wght 200-800, wdth 100-125, slant 0 to 11 deg, SIL OFL 1.1, via jsDelivr; fallback monospace.

**Colour.** Canvas #e7b7a8; primary #3a1f2a (8.3:1); secondary #803551 (4.6:1, labels and actions).

**Rules.** Right-aligned block, vertically centred; the name upright 6.6vw weight 800; every other line obliqued 11 deg, sizes falling from 3.4vw to 1.1vw and width from 125 to 100.

**Signature relationship.** Upright against oblique: the rooted name in the wind.

**Must stay if it continues.** Downwind alignment; slant as wind; the upright name.

**Assumptions and risks.** Working copy is the demo's own UI words. Fonts load from GitHub branches through jsDelivr (not pinned to a release). Radon's handwritten character may read informal for controls.

**Into Round 2.** Carry the signature relationship into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
