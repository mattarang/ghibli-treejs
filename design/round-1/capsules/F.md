# F

**Premise.** Every tree comes back exactly from its seed number: a fixed character grid, one size, values in fixed columns, the same place every time.

**Fonts and licence.** Departure Mono (Tobias Fried, US), Regular, MIT licence, via jsDelivr; fallback monospace.

**Colour.** Canvas #d7d2e8; primary #2d2550 (9.6:1, values and name); secondary #5d538d (4.6:1, labels and app lines).

**Rules.** One size (clamp 16.5-44px); 24-character lines padded with spaces; values right-aligned in column; blank lines as the only spacing; block anchored bottom right.

**Signature relationship.** One size, one grid: hierarchy only by column and ink.

**Must stay if it continues.** Fixed 24-character grid; single size; two inks.

**Assumptions and risks.** Working copy is the demo's own UI words. Fonts load from GitHub branches through jsDelivr (not pinned to a release). Pixel font: sharpest at multiples of 11px.

**Into Round 2.** Carry the signature relationship into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
