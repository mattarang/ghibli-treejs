# E

**Premise.** Size against a 1.7 m person: type set at real size, one metre to one unit, so Height and Trunk height stand on one ground line at true proportion.

**Fonts and licence.** Ostrich Sans (Tyler Finck, The League of Moveable Type, US), Light/Regular/Bold/Black, SIL OFL 1.1, via jsDelivr; caps only.

**Colour.** Canvas #9fc7d9; one text colour #0d2230 (9.0:1).

**Rules.** Unit u = min(5.2vh, 3.4vw); 12.5 m at 12.5u, 1.9 m at 1.9u; all other text 1.4-1.9vw in a loose top band.

**Signature relationship.** Font size as metres.

**Must stay if it continues.** The one-unit-per-metre rule; a shared ground line; one ink.

**Assumptions and risks.** Working copy is the demo's own UI words. Fonts load from GitHub branches through jsDelivr (not pinned to a release). The 12.5 m figure gets very wide on large landscape screens.

**Into Round 2.** Carry the signature relationship into the demo's real controls (tree chip, Shape panel, sun and season dials, boot screen) without normalising it into a standard panel.
